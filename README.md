# 沖繩自駕小旅行網頁（調整版）

## 使用方式
1. 解壓縮 ZIP。
2. 可先用瀏覽器開啟 `index.html` 預覽。
3. 將資料夾內的 `index.html`、`style.css`、`app.js` 上傳至 GitHub repository 根目錄。
4. GitHub → Settings → Pages → Build and deployment，選擇 Deploy from a branch。
5. Branch 選 `main`、資料夾選 `/ (root)`，儲存後等待部署完成。
6. 將 GitHub Pages 網址分享給同行旅客即可。

## 檔案
- `index.html`：網頁結構
- `style.css`：奶油鵝黃色版型、桌機與手機排版
- `app.js`：五日行程、日期切換、Map Code 複製
- `MAPCODE_AUDIT.md`：內部核對紀錄（不會顯示在旅客網站上）

## Map Code 顯示原則
只保留有可查證來源能對應到該地點的代碼；無法確認或不同來源互相衝突的代碼，已從網站資料中移除。頁面不顯示核對來源或待核對狀態。導航時仍請確認目的地名稱及入口。
